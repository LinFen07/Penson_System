### 3. **状态管理规则**

#### Pinia Store 设计

```ts
// stores/leetcode.store.ts
export const useLeetcodeStore = defineStore("leetcode", () => {
  // 状态
  const problemList = ref<LeetcodeProblem[]>([]);
  const heatmapData = ref<HeatmapItem[]>([]);

  // Getter
  const unsolvedProblems = computed(() =>
    problemList.value.filter((p) => !p.solved)
  );

  // Action
  const fetchProblems = async () => {
    const { data } = await leetcodeApi.getProblems();
    problemList.value = data;
    // 必须更新热力图
    updateHeatmap();
  };

  return { problemList, heatmapData, unsolvedProblems, fetchProblems };
});
```

#### 使用限制：

1. 组件中必须使用`storeToRefs()`解构
2. 跨组件状态修改必须通过 actions
3. 复杂状态变更需记录日志

### 5. **组合式函数开发标准**

```ts
// composables/useAlgorithmVisualizer.ts
export default function (canvasRef: Ref<HTMLCanvasElement>) {
  // 私有状态
  const animationFrame = ref<number | null>(null);

  // 公开方法
  const visualizeSort = (steps: AlgorithmStep[]) => {
    cancelAnimation();
    // 核心动画逻辑...
  };

  // 必须清理资源
  const cancelAnimation = () => {
    if (animationFrame.value) {
      cancelAnimationFrame(animationFrame.value);
    }
  };

  // 自动清理
  onScopeDispose(cancelAnimation);

  return { visualizeSort, cancelAnimation };
}
```

#### 强制要求：

1. 以`use`前缀命名
2. 返回对象不超过 5 个属性
3. 必须处理资源清理

### 9. **错误处理协议**

#### 全局错误拦截

```ts
// http.ts
http.interceptors.response.use(null, (error) => {
  const errorMap = {
    401: "请重新登录",
    500: "服务器内部错误",
    timeout: "请求超时",
  };

  // 根据类型显示通知
  showNotification(errorMap[error.code] || "未知错误");

  // 关键错误上报
  if (error.isCritical) {
    logErrorToServer(error);
  }

  return Promise.reject(error);
});
```

#### 客户端错误分级

```ts
// 错误处理策略：
1. UI操作错误: 即时Toast提示
2. 数据提交错误: 表单内标红+说明
3. 算法执行错误: 控制台高亮+代码定位
4. 网络错误: 自动重试机制
5. 崩溃级错误: 上报服务器+页面恢复
```
